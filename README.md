- **Excel** — Powerful spreadsheet tool for data analysis, visualization, and trend identification.
- **PowerPoint** — Easy-to-use presentation software with templates, animations, and video integration.
- **Visio** — Create flow charts and organizational diagrams effortlessly.
- **Project** — Manage projects, assign resources, and track progress seamlessly.
- **Outlook** — Comprehensive email client for managing communications and contacts.
